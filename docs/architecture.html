Auth Flow

sequenceDiagram participant B as Browser participant S as Server rect rgb(30, 42, 48) Note over B,S: Registration B->>B: generate keypair alice_pub / alice_priv B->>B: wrap_key = Argon2(password) B->>B: encrypted_priv = encrypt(alice_priv, wrap_key) B->>S: POST /users { email, pubkey, fingerprint, encrypted_privkey } S->>S: user_id = HMAC(email, PEPPER) S->>S: store { user_id, pubkey, fingerprint, encrypted_privkey } Note right of S: email discarded S-->>B: 201 OK end rect rgb(30, 42, 30) Note over B,S: Login B->>S: POST /auth/init { email } S->>S: HMAC(email, PEPPER) → lookup record S-->>B: { encrypted_privkey, challenge } B->>B: privkey = decrypt(encrypted_privkey, Argon2(password)) B->>B: sig = sign(challenge, privkey) B->>S: POST /auth/verify { fingerprint, sig } S->>S: verify(sig, challenge, pubkey) ✓ S-->>B: { jwt } end

Invite Flow

sequenceDiagram participant A as Alice (member) participant S as Server participant B as Bob (new) A->>S: POST /invites { workspace_id } S->>S: generate one-time token S-->>A: { token } Note over A,B: Alice shares link out-of-band Note over A,B: https://app/invite#token B->>S: POST /users { pubkey, fingerprint, encrypted_privkey } S-->>B: 201 OK B->>S: POST /invites/claim { token, bob_fp } S->>S: validate token S->>A: notify: bob_fp wants to join loop For each workspace card A->>A: DEK = decrypt(keys[alice_fp], alice_priv) A->>A: enc_DEK_bob = encrypt(DEK, bob_pub) A->>S: PATCH /cards/{id}/keys { bob_fp: enc_DEK_bob } end Note over B,S: Bob can now decrypt all cards Note right of S: Server never learned Bob's email

Writing a Card

sequenceDiagram participant B as Browser (Alice) participant S as Server B->>B: 1. generate random DEK B->>B: 2. ciphertext = AES-256-GCM(payload, DEK) B->>B: 3. enc_DEK[alice_fp] = OpenPGP.encrypt(DEK, alice_pub) B->>B: 3. enc_DEK[bob_fp] = OpenPGP.encrypt(DEK, bob_pub) B->>B: 4. signature = OpenPGP.sign(ciphertext, alice_priv) B->>S: POST /cards Note right of B: { workspace_id, column_id, position,\nciphertext, signed_by: alice_fp,\nsignature, keys: { alice_fp:…, bob_fp:… } } Note right of S: Stores opaque blob\nKnows: workspace, column, position\nKnows nothing: title, dates, content
